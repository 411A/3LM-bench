prompts that informed fixes. They may contain point-in-time counts, assumptions,
or operational details that no longer apply. For current behavior, use
[`README.md`](../../README.md), [`METHODOLOGY.md`](../METHODOLOGY.md), the
benchmark catalog, and the current code/tests.

- [`reviews/`](reviews/) — chronological correctness, methodology, and
  operational investigations.
- [`auditing/AUDIT_PROMPT.md`](auditing/AUDIT_PROMPT.md) — an archived prompt
  for adversarial review; verify its assumptions against current sources before
  reusing it.
